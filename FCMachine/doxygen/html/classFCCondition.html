Подробное описание

Класс для компактного хранения и управления составным состоянием устройства.

Объединяет шесть независимых состояний в единое 16-битное битовое поле:

  • Готовность (ReadyState) — биты 0-1 (2 бита),
  • Воспроизведение (PlayState) — биты 2-3 (2 бита),
  • Изменение (ChangedState) — бит 4 (1 бит),
  • Ошибка (ErrorType) — биты 5-9 (5 бит),
  • Панель (PanelState) — биты 10-11 (2 бита),
  • Видимость (VisibilityState) — бит 12 (1 бит),
  • Зарезервировано — биты 13-15 (3 бита, всегда 0).

Преимущества:

  • Минимальный размер (ровно 2 байта),
  • Атомарное чтение/запись состояния (важно для многопоточных систем),
  • Эффективная сериализация для передачи по сети или сохранения в память,
  • Тривиальная копируемость (trivially copyable) для использования в встраиваемых системах.
Заметки
Класс спроектирован для использования в ресурсоограниченных средах (включая микроконтроллеры). Все операции реализованы как constexpr и noexcept для максимальной эффективности.
Предупреждения
Зарезервированные биты (13-15) всегда очищаются при десериализации для обеспечения совместимости между версиями.
