Подробное описание

Модальный диалог подтверждения с двумя кнопками "Да" и "Нет".

Предназначен для запроса подтверждения критических действий у пользователя:

  • Удаление файлов или данных,
  • Прерывание текущей операции,
  • Изменение системных настроек,
  • Завершение работы приложения с несохранёнными данными.

Особенности реализации:

  • Использует генерируемый Qt Designer UI-класс (Ui::FCYesNoDialog),
  • Стандартное поведение QDialog: возвращает Accepted при "Да", Rejected при "Нет",
  • Дополнительно эмитирует кастомные сигналы yes()/no() для реактивного программирования,
  • Поддерживает установку сообщения как до отображения (через setMessage()), так и динамически во время работы диалога.

Семантика возвратных значений:

  • "Да" → QDialog::Accepted (код 1),
  • "Нет" → QDialog::Rejected (код 0).
Предупреждения
ВАЖНО: В текущей реализации UI кнопки реализованы как QToolButton, а не QPushButton. Это требует особой обработки "кнопки по умолчанию":
  • QToolButton не поддерживает setDefault() — для эмуляции поведения кнопки по умолчанию необходимо использовать QShortcut для клавиши Enter,
  • Рекомендуется заменить QToolButton на QPushButton в Qt Designer для стандартного поведения диалогов (см. примечание в реализации).
Заметки
Класс предназначен ТОЛЬКО для хост-систем с графическим интерфейсом (ПК, планшеты). Не подходит для встраиваемых систем без дисплея или с ограниченными ресурсами.
Предупреждения
Диалог НЕ является потокобезопасным — все операции должны выполняться в основном потоке (потоке событий Qt).

int FCYesNoDialog::exec ( )
override

Отображает диалог в модальном режиме и возвращает результат подтверждения.

Возвращает
QDialog::Accepted (1) если пользователь нажал "Да", QDialog::Rejected (0) если пользователь нажал "Нет" или закрыл диалог.
Заметки
Рекомендуемый способ использования:
if (FCYesNoDialog("Удалить файл?").exec() == QDialog::Accepted) {
// Выполнить удаление
}

◆ no

void FCYesNoDialog::no ( )
signal

Сигнал, эмитируемый при отказе от действия пользователем (нажатие "Нет").

Заметки
Сигнал эмитируется ДО закрытия диалога и установки результата Rejected. Позволяет выполнить дополнительные действия перед завершением диалога.
Предупреждения
Не заменяет стандартный результат QDialog::Rejected — используйте оба механизма в зависимости от архитектуры приложения.

◆ setMessage()

void FCYesNoDialog::setMessage ( const QString & message)

Устанавливает текст запроса подтверждения для отображения в диалоге.

Аргументы
messageТекст запроса (поддерживает HTML-форматирование для Qt-виджетов).
Заметки
Метод можно вызывать как до вызова exec()/show(), так и во время отображения диалога. Для многострочных сообщений используйте "\n" или "<br>" (в HTML-режиме).
Предупреждения
Длинные сообщения (>500 символов) могут нарушить макет диалога — рекомендуется ограничивать длину или использовать многострочный режим в дизайнере.
