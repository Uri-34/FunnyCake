Подробное описание

Базовый класс для всех устройств, подключаемых по шине I²C.

Предоставляет унифицированный интерфейс для работы с периферийными устройствами:

  • Хранение адреса устройства на шине,
  • Удобные методы ввода-вывода с автоматической установкой состояния при ошибках,
  • Интеграция в систему управления состоянием через FCConditionObject,
  • Поддержка иерархии владения памятью через механизм родительства QObject.

Особенности архитектуры:

  • ВСЕ методы ввода-вывода автоматически устанавливают состояние устройства при ошибках через ГРУППОВЫЕ вызовы set({ ... }) для минимизации эмиссии сигналов,
  • Проверка ошибок шины выполняется через is(ErrorType::NoError) базового класса,
  • Отсутствие проксирования сигналов состояния шины — состояние устройства управляется ТОЛЬКО его собственными методами через conditionChanged() базового класса.

Семантика ошибок шины:

Условие ошибки Устанавливаемое состояние
_bus == nullptr {Error, Stop, Changed, ConnectionError}
Ошибка записи в шину {Error, Stop, Changed, WriteDataError}
Ошибка чтения из шины {Error, Stop, Changed, ReadDataError}
Успешная операция {Ready, Stop, NotChanged, NoError}
Предупреждения
Критически важно:
  • НИКОГДА не вызывать методы шины напрямую из потомков — ВСЕГДА используйте методы базового класса (readByte, writeRegister и т.д.) для гарантии корректной установки состояния,
  • При использовании нескольких устройств на одной шине убедитесь в уникальности адресов.
Заметки
Для встраиваемых систем (Raspberry Pi 4 + Buildroot):
  • Шина I²C должна быть инициализирована ДО создания устройств,
  • Рекомендуется использовать аппаратную шину (/dev/i2c-1) вместо программной,
  • Все операции блокируют вызывающий поток на время транзакции шины.

Конструктор устройства с привязкой к шине I²C.

Аргументы
busУказатель на шину I²C (должна быть инициализирована заранее).
address7-битный адрес устройства на шине (0x00–0x7F).
nameИмя устройства для идентификации в системе.
parentРодительский QObject для управления временем жизни.
Заметки
При создании:
  • Выполняется валидация параметров (шину и адрес),
  • При ошибках валидации устанавливается состояние ошибки,
  • При успешной валидации сохраняется начальное состояние от FCDevice (NotReady, Stop, NotChanged, NoError).
Предупреждения
Bus НЕ ДОЛЖЕН быть nullptr — это приведёт к установке ErrorType::ConnectionError.
