Подробное описание

Класс управления печатающей головкой плоттера с множественными соплами.

Представляет физическую головку плоттера, оснащённую несколькими соплами для нанесения краски/чернил разной толщины или цвета. Обеспечивает:

  • Хранение геометрических параметров каждого сопла (позиция, диаметр),
  • Управление состоянием сопел через шину I2C (включение/выключение подачи),
  • Преобразование координат между системой головки и глобальной системой плоттера,
  • Калибровку относительного положения сопел для точного позиционирования.

Топология головки:

  • Конфигурация 1×3 (1 ряд, 3 столбца) — три сопла в горизонтальной линии,
  • Сопла расположены с фиксированным шагом для совместимости с механическим креплением,
  • Каждое сопло имеет уникальный диаметр для нанесения линий разной толщины:
    • Сопло 0: 0.4 мм — тонкие линии, детализация,
    • Сопло 1: 0.7 мм — средние линии, заливка,
    • Сопло 2: 0.5 мм — универсальное назначение.

Особенности реализации:

  • Наследуется от FCI2CDevice для интеграции в шину I2C управления периферией,
  • Все сопла инициализируются статически при создании объекта (конфигурация неизменна),
  • Доступ к соплам выполняется через безопасные методы с проверкой границ,
  • Поддержка калибровочных смещений для компенсации механических допусков.
Предупреждения
Критически важно:
  • Конфигурация сопел (количество, расположение, диаметр) задаётся на этапе проектирования и не может быть изменена программно во время выполнения,
  • Все координаты сопел задаются в локальной системе координат головки (мм), преобразование в глобальную систему выполняется внешними компонентами (плоттером).
Заметки
Для встраиваемых систем (Raspberry Pi 4 + Buildroot):
  • Данные о соплах хранятся в стеке (не в куче) для минимизации фрагментации памяти,
  • Все методы доступа к соплам являются константными и не вызывают выделения памяти,
  • Рекомендуется кэшировать часто используемые параметры (диаметр активного сопла) в рабочем потоке.

  • Сопло 1: позиция (15, 5) мм, диаметр 0.7 мм, калибровочное смещение 0,
  • Сопло 2: позиция (5, 15) мм, диаметр 0.5 мм, калибровочное смещение 0.

◆ nozzle()

const FCNozzle & FCHead::nozzle ( int index) const
inlinenoexcept

Возвращает сопло по индексу с автоматической проверкой границ.

Аргументы
indexИндекс сопла в диапазоне [0, nozzleCount() - 1].
Возвращает
Константная ссылка на объект сопла.
Заметки
При выходе индекса за допустимые границы возвращается крайнее допустимое сопло:
  • Индекс < 0 → возвращается сопло 0,
  • Индекс ≥ nozzleCount() → возвращается последнее сопло (nozzleCount() - 1).
Предупреждения
Для строгой проверки границ используйте метод isValidNozzleIndex() перед вызовом.
