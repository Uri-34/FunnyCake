Подробное описание

Драйвер цифрового датчика температуры LM75A с интерфейсом I²C.

LM75A — промышленный датчик температуры с высокой точностью и низким энергопотреблением:

  • Диапазон измерений: -55 °C до +125 °C,
  • Точность: ±1.5 °C в диапазоне -25 °C до +100 °C,
  • Разрешение: 9, 10, 11 или 12 бит (по умолчанию 9 бит = 0.5 °C),
  • Напряжение питания: 2.8 В – 5.5 В,
  • Ток потребления: 250 мкА в активном режиме, 3.5 мкА в режиме отключения.

Особенности архитектуры:

  • ВСЕ ошибки и состояния управляются через составное состояние FCCondition,
  • Полный отказ от логирования в консоль и избыточных сигналов,
  • Групповые установки состояния для минимизации эмиссии сигналов,
  • Автоматическая компенсация калибровки (+1.0 °C),
  • Защита от слишком частого опроса (минимум 27 мс),
  • Режим отключения для энергосбережения.

Диагностика:

  • Проверка состояния через hasError(), error(), is(ErrorType::...),
  • Подписка на сигнал conditionChanged() базового класса для реакции на ошибки,
  • Сигнал temperatureChanged() эмитируется ТОЛЬКО при превышении порога изменения.
Предупреждения
Все операции устанавливают состояние через групповой set() для минимизации количества эмиссий сигнала conditionChanged(). Каждый вызов set(...) с разным состоянием эмитирует сигнал — групповые установки критичны для производительности.
Заметки
Для встраиваемых систем: минимальное потребление памяти, отсутствие аллокаций в критических путях, предсказуемое время выполнения операций.

Конструктор датчика температуры с привязкой к шине I²C.

Аргументы
busУказатель на шину I²C для обмена данными.
address7-битный адрес датчика на шине (по умолчанию 0x48).
nameИмя устройства для идентификации в системе (например, "AmbientSensor").
parentРодительский QObject для управления временем жизни.
Заметки
При создании автоматически:
  • Устанавливается компенсация +1.0 °C для коррекции систематической погрешности,
  • Настраивается порог изменения 0.5 °C для эмиссии сигналов,
  • Датчик остаётся в режиме отключения (для экономии энергии) до первого вызова temperatureC(),
  • Выполняется ГРУППОВАЯ установка состояния (один сигнал вместо трёх).

◆ temperatureC()

float FCLM75AThermometer::temperatureC ( )

Возвращает текущую температуру в градусах Цельсия.

Возвращает
Значение температуры с учётом компенсации калибровки.
Заметки
Метод автоматически:
  • Проверяет минимальную задержку между опросами (27 мс для 9-битного режима),
  • Включает датчик, если он находился в режиме отключения,
  • Применяет компенсацию калибровки,
  • Эмитирует сигнал temperatureChanged() при превышении порога _deltaThreshold.
Предупреждения
Блокирует вызывающий поток на время преобразования (до 216 мс для 12-битного режима).
