Подробное описание

Класс для выполнения FCThreadProcess в отдельном потоке.

Управляет жизненным циклом процесса и потока. Состояние (ready/play/error) — берётся из _process, а не дублируется.

⚠️ ВАЖНО: FCThreader НЕ наследует FCStatedObject. Вместо этого — делегирует запросы к процессу через прокси-методы.

Это гарантирует:

  • согласованность состояния,
  • отсутствие дублирования данных (экономия RAM в embedded),
  • прозрачность: состояние = состояние процесса.

Предупреждения
Не вызывайте методы управления (start/stop) напрямую — используйте FCThreader.

◆ start()

void FCThreader::start ( )

Запустить процесс в отдельном потоке. Выполняет:

  1. process->moveToThread(_thread)
  2. connect сигналов (started/stopped/paused → emit)
  3. start потока
  4. вызов process->start() через queued connection

◆ stop()

void FCThreader::stop ( )

Остановить процесс и завершить поток.

Выполняет graceful shutdown:

  • вызов process->stop(),
  • ожидание завершения через process->finished(),
  • quit() + wait() потока.
