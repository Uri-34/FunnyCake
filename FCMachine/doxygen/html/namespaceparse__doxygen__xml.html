Подробное описание

Парсер XML-документации doxygen для генерации PROJECT_MEMORY.dox

Использование:
    python3 parse_doxygen_xml.py [--output-dir DIR] [--xml-dir DIR] [--verbose]

Параметры:
    --output-dir DIR    Директория для сохранения PROJECT_MEMORY.dox (по умолчанию: ./docs)
    --xml-dir DIR       Директория с XML-файлами doxygen (по умолчанию: ./docs/xml_memory)
    --verbose, -v       Вывод подробной информации о процессе
    --help, -h          Показать справку и выйти
