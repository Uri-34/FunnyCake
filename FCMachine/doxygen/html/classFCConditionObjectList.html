Подробное описание

template<typename T>
class FCConditionObjectList< T >

Вспомогательный шаблонный класс для управления коллекцией объектов с состоянием.

Предоставляет удобные методы для массовой проверки состояния группы объектов:

  • Проверка, что ВСЕ объекты находятся в заданном состоянии,
  • Поддержка пустых коллекций (согласно принципу "истина по умолчанию" для универсальных кванторов).
Параметры шаблона
TТип объектов в коллекции, должен быть производным от FCConditionObject и иметь метод is().
Заметки
Реализован как наследник QList<T> для прямого доступа ко всем методам контейнера.
Предупреждения
Пустая коллекция возвращает true для всех проверок is() — это соответствует логике "все элементы коллекции удовлетворяют условию" для пустого множества.
