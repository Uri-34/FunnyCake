Подробное описание

Область построения для 3D-плоттера: общие размеры + сетка ячеек.

Семантика:

  • totalSize() = (W, H, D) в мм — общие размеры области,
  • gridSize() = (Nx, Ny, Nz) — количество ячеек по осям,
  • cellSize() = (W/Nx, H/Ny, D/Nz) — размер одной ячейки.

Пример: область 100×50×20 мм, сетка 10×5×2 → ячейка 10×10×10 мм.
