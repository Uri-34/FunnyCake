Подробное описание

Базовый класс для объектов с управляемым составным состоянием и уведомлениями об изменениях.

Расширяет функционал FCCondition возможностями фреймворка Qt:

  • Интеграция с системой сигналов/слотов для реактивного программирования,
  • Поддержка иерархии объектов через механизм родительства QObject,
  • Именование объектов для отладки и логирования.

Особенности поведения сеттеров:

  • При изменении состояния автоматически устанавливается флаг ChangedState::Changed,
  • При установке ошибки (ErrorType ≠ NoError) автоматически переводится в состояние ReadyState::Error,
  • При установке валидного состояния готовности (Ready/NotReady) автоматически сбрасывается ошибка в NoError,
  • Сигнал conditionChanged() эмитируется ТОЛЬКО при фактическом изменении состояния.
Предупреждения
Класс наследуется от QObject и поэтому НЕ является тривиальным (non-trivial). Не может использоваться в контекстах, требующих trivially_copyable типов.
Заметки
Для проверки состояния группы объектов используйте вспомогательный шаблонный класс FCConditionObjectList<T>.
