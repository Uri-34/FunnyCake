Подробное описание

Базовый класс для объектов с управляемым состоянием (готовность, воспроизведение, ошибки).

Предоставляет:

  • Единый интерфейс состояния через Condition,
  • Типобезопасные геттеры/сеттеры с проверкой изменений,
  • Сигнал conditionChanged() для реактивного UI,
  • Интеграцию с Qt: Q_PROPERTY, QML, Designer.
Заметки
Использует композицию вместо наследования — безопасно и гибко.
