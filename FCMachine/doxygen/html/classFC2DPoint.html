Подробное описание

Класс для представления двумерной точки с координатами (x, y).

Предоставляет функционал для геометрических операций: вычисление расстояний, углов, нормализация векторов, преобразования координат и арифметические операции. Класс спроектирован как тривиальный (trivially copyable) для эффективной работы в контейнерах и возможности использования в constexpr-контекстах (требуется C++23 для методов с тригонометрическими функциями).
