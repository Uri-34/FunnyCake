Подробное описание

Базовый класс для I²C-управляемых с PCF8575 помощью индикаторов (LED).

Поддерживает:

  • ручное включение/выключение,
  • автоматическое мигание (blink),
  • работу через I²C expander (PCF8574/PCF8575).
