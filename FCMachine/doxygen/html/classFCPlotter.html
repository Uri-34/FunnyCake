Подробное описание

Класс управления промышленным плоттером в отдельном потоке выполнения.

Предназначен для параллельного управления несколькими плоттерами на одной встраиваемой платформе (Raspberry Pi 4 + Buildroot). Каждый экземпляр работает в собственном потоке QThread для изоляции операций и предотвращения блокировок основного потока интерфейса.

Ключевые возможности:

  • Параллельное выполнение операций нанесения на нескольких устройствах,
  • Генерация и выполнение G-code последовательностей из векторных моделей (SVG),
  • Управление механическими компонентами через контроллер Marlin (оси X/Y/Z),
  • Контроль подачи краски через насосную рампу (ШИМ-управление),
  • Потокобезопасная диагностика и обработка ошибок,
  • Гибкое управление жизненным циклом (старт/пауза/стоп/сброс) через сигналы/слоты.

Архитектура многопоточности:

  • Каждый плоттер работает в собственном экземпляре QThread (не наследует QThread!),
  • Взаимодействие с основным потоком осуществляется ТОЛЬКО через сигналы/слоты,
  • Все публичные методы (start/stop/pause) являются неблокирующими — они ставят задачу в очередь рабочего потока и немедленно возвращаются,
  • Внутреннее состояние защищено мьютексом QMutex для предотвращения гонок данных,
  • Ожидание завершения операций реализовано через QWaitCondition вместо активного ожидания.

Особенности для встраиваемых систем (Raspberry Pi 4):

  • Поддержка до 4 плоттеров одновременно (ограничение по количеству аппаратных UART),
  • Общая шина I2C требует синхронизации доступа через отдельный менеджер шины,
  • Ограничение общей нагрузки на ШИМ-выходы (макс. 4 канала на Raspberry Pi 4),
  • Приоритизация потоков: основной интерфейс > плоттеры > фоновые задачи.
Предупреждения
Критически важно:
  • НИКОГДА не вызывать публичные методы напрямую из рабочего потока — только через сигналы,
  • Все доступы к разделяемым ресурсам (особенно шина I2C) должны быть синхронизированы,
  • При уничтожении объекта необходимо корректно завершить рабочий поток через stopThread().
Заметки
Для оптимальной работы на Raspberry Pi 4:
  • Назначьте потокам плоттеров приоритет реального времени (SCHED_FIFO, priority 50-70),
  • Используйте аппаратные UART вместо программных для связи с контроллерами Marlin,
  • Разнесите плоттеры по разным шинам I2C (через мультиплексор) для устранения конфликтов.

FCDevice для базовой функциональности управления устройствами
FCMarlinController для низкоуровневого управления движением
FCI2CBusManager для синхронизированного доступа к общей шине I2C

FCI2CBus * bus,

explicit

Конструктор плоттера с настройкой рабочего потока.

Аргументы
serialNumberУникальный серийный номер плоттера (для идентификации в системе).
parentРодительский QObject для управления временем жизни.
Заметки
При создании автоматически:
  • Создаётся и запускается рабочий поток QThread,
  • Объект перемещается в рабочий поток через moveToThread(),
  • Инициализируются компоненты управления (контроллер, насосная рампа),
  • Устанавливается начальное состояние "не готов" (ReadyState::NotReady).
Предупреждения
Сериальный номер должен быть уникальным для каждого плоттера в системе.

◆ ~FCPlotter()

FCPlotter::~FCPlotter ( )
override

Деструктор плоттера с корректным завершением рабочего потока.

Заметки
Автоматически выполняет:
  • Отправку команды остановки в рабочий поток,
  • Ожидание завершения всех операций (макс. 5 секунд),
  • Принудительное завершение потока при таймауте,
  • Освобождение всех ресурсов (контроллер, насосная рампа, буферы).
Предупреждения
Блокирует вызывающий поток на время ожидания завершения (до 5 секунд).
