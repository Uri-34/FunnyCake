Подробное описание

Абстрактный класс для потокового процесса с состоянием.

Наследует QObject → имеет:

  • композитное состояние → _condition (ready/play/changed/error/...),
  • сигнал conditionChanged(),
  • свойства для Qt (Q_PROPERTY).

Предназначен для реализации фоновых задач (опрос датчиков, обработка данных и т.п.).
