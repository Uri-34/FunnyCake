Подробное описание

Модальный диалог отображения ошибок с кнопкой подтверждения.

Предназначен для визуализации текстовых сообщений об ошибках в графическом интерфейсе:

  • Отображает однострочное или многострочное сообщение в центральной части диалога,
  • Предоставляет единственную кнопку "OK" для подтверждения и закрытия диалога,
  • Автоматически эмитирует сигнал ok() при закрытии через кнопку "OK".

Особенности реализации:

  • Использует генерируемый Qt Designer UI-класс (Ui::FCErrorDialog),
  • Поддерживает установку сообщения как до отображения (через setMessage()), так и динамически во время работы диалога,
  • Является модальным диалогом по умолчанию (exec()), но может использоваться как немодальный (show()) при необходимости.
Заметки
Класс предназначен ТОЛЬКО для хост-систем с графическим интерфейсом (ПК, планшеты). Не подходит для встраиваемых систем без дисплея или с ограниченными ресурсами.
Предупреждения
Диалог НЕ является потокобезопасным — все операции должны выполняться в основном потоке (потоке событий Qt).
См. также
FCCommand для обработки ошибок на уровне протокола
FCCondition для управления состоянием ошибок в устройстве

Методы

◆ exec()

int FCErrorDialog::exec ( )
override

Отображает диалог в модальном режиме и возвращает результат.

Возвращает
QDialog::Accepted если пользователь нажал "OK", иначе QDialog::Rejected.
Заметки
Этот метод является стандартным для QDialog и вызывается неявно при exec(). Рекомендуется использовать именно exec() для модальных диалогов ошибок.

◆ ok

void FCErrorDialog::ok ( )
signal

Сигнал, эмитируемый при подтверждении ошибки пользователем (нажатие "OK").

Заметки
Сигнал эмитируется ДО закрытия диалога, что позволяет выполнить дополнительные действия перед уничтожением объекта (например, логирование подтверждения).
Предупреждения
Не путать с сигналом QDialog::finished() — этот сигнал специфичен для подтверждения ошибки.

◆ setMessage()

void FCErrorDialog::setMessage ( const QString & message)

Устанавливает текст сообщения об ошибке для отображения в диалоге.

Аргументы
messageТекст сообщения (поддерживает HTML-форматирование для Qt-виджетов).
Заметки
Метод можно вызывать как до вызова exec()/show(), так и во время отображения диалога. Для многострочных сообщений используйте "\n" или "<br>" (в HTML-режиме).
Предупреждения
Длинные сообщения (>500 символов) могут нарушить макет диалога — рекомендуется ограничивать длину или использовать многострочный режим в дизайнере.
