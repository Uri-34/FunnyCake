Подробное описание

Класс для представления двумерной области, разбитой на регулярную сетку ячеек.

Область определяется тремя параметрами:

  • startPoint — координаты левого верхнего угла области,
  • areaSize — полный размер области (ширина × высота),
  • cellCounts — количество ячеек по осям X и Y (Nx, Ny), минимум 1×1.

Каждая ячейка имеет одинаковый размер: (areaSize.width / Nx, areaSize.height / Ny). Класс предоставляет доступ к ячейкам по индексам, координатам точки, а также поддерживает кастомный порядок обхода ячеек для алгоритмов сканирования.

Заметки
Класс нетривиален из-за использования QVector для хранения порядка обхода, поэтому не все методы могут быть constexpr.

Конструктор с параметрами.

Аргументы
startPointНачальная точка области (левый верхний угол).
areaSizeРазмер всей области (по умолчанию 1×1).
