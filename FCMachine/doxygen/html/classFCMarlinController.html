Подробное описание

Низкоуровневый драйвер управления контроллером на базе прошивки Marlin 2.1.2.4.

Предоставляет интерфейс для взаимодействия с аппаратным контроллером плоттера (обычно на базе платы BigTreeTech SKR или аналогичной) через последовательный порт UART. Обеспечивает:

  • Установку и разрыв соединения с контроллером,
  • Отправку и приём G-code/M-code команд с таймаутами,
  • Парсинг ответов контроллера и извлечение диагностических данных,
  • Управление периферийными устройствами (светодиодная лента через адресные ленты),
  • Экстренную остановку и восстановление после ошибок,
  • Загрузку конфигурационных данных из прошивки (команда M115).

Особенности реализации:

  • Поддержка стандартного протокола обмена Marlin (окончание команды "\n", подтверждение "ok\n"),
  • Автоматическая повторная отправка команд при таймаутах (до 3 попыток),
  • Потокобезопасный доступ к последовательному порту через внутренний мьютекс,
  • Валидация контрольных сумм для критически важных команд,
  • Поддержка длинных ответов контроллера (буферизация до 1024 байт).

Совместимость:

  • Прошивка: Marlin 2.1.2.4 и выше (режим "подтверждения без эха"),
  • Скорость порта: 115200 бод (стандарт для большинства конфигураций),
  • Аппаратное управление потоком: отключено (программное управление через таймауты).
Предупреждения
Критически важно:
  • Последовательный порт НЕ является потокобезопасным на уровне ОС — все операции с портом должны выполняться в ОДНОМ потоке (обычно рабочем потоке плоттера),
  • При использовании нескольких плоттеров на одном устройстве каждый должен иметь СОБСТВЕННЫЙ аппаратный UART (не программный через GPIO),
  • Не отправлять команды во время активной передачи — дожидаться подтверждения "ok".
Заметки
Для встраиваемых систем (Raspberry Pi 4 + Buildroot):
  • Используйте ТОЛЬКО аппаратные UART (/dev/ttyAMA0, /dev/ttyS0) для критичных операций,
  • Избегайте программных UART (через библиотеки типа pigpio) из-за нестабильности таймингов,
  • Настройте параметры порта через device tree overlay для предотвращения конфликтов с консолью,
  • Установите приоритет потока контроллера выше, чем у интерфейса (но ниже, чем у прерываний).

Конструктор контроллера с указанием порта и шины I2C.

Аргументы
portNameИмя последовательного порта (например, "/dev/ttyAMA0" на Raspberry Pi).

Предупреждения
Порт должен быть доступен для чтения/записи текущим пользователем (права uucp/dialout).

◆ checkConnection()

bool FCMarlinController::checkConnection ( )

Проверяет связь с контроллером отправкой тестовой команды.

Возвращает
true если контроллер ответил подтверждением "ok" в течение таймаута; иначе — false.
Заметки
Отправляет команду M105 (запрос температуры) и ожидает ответ в течение 1 секунды. Используется для периодической проверки живости соединения.
Предупреждения
Блокирует вызывающий поток на время ожидания ответа (до 1 секунды).

◆ connect()

bool FCMarlinController::connect ( )

Устанавливает соединение с контроллером через последовательный порт.

Возвращает
true при успешном открытии порта и подтверждении связи; иначе — false.
Заметки
Алгоритм:
  1. Открытие порта с параметрами: 115200 бод, 8N1, без управления потоком,
  2. Очистка буферов приёмника/передатчика,
  3. Отправка команды M105 (запрос температуры) для проверки связи,
  4. Ожидание подтверждения "ok" в течение 2 секунд.
Предупреждения
Блокирует вызывающий поток на время установки соединения (до 2 секунд).

◆ emergencyStop()

void FCMarlinController::emergencyStop ( )

Выполняет экстренную остановку всех операций контроллера.

Заметки
Отправляет команду "M112" (аварийная остановка в Marlin) с немедленным сбросом буферов. После выполнения все движения прекращаются, двигатели отключаются. Требуется ручная перезагрузка контроллера или отправка "M999" для восстановления.

◆ sendCommand()

bool FCMarlinController::sendCommand ( const QString & command)

Отправляет одиночную G-code/M-code команду в контроллер.

Аргументы
commandСтрока команды без символа новой строки (например, "G1 X10 Y20 F1500").
Возвращает
true если команда отправлена И получено подтверждение "ok"; иначе — false.
Заметки
Автоматически добавляет "\n" в конец команды и ожидает подтверждение "ok" с таймаутом 1 секунда. При таймауте выполняется до 3 попыток повторной отправки.
Предупреждения
Блокирует вызывающий поток на время ожидания подтверждения (до 3 секунд при неудачах).

◆ sendCommands()

bool FCMarlinController::sendCommands ( const QStringList & commands)

Отправляет список G-code команд последовательно.

Аргументы
commandsСписок команд для отправки (каждая без символа новой строки).
Возвращает
true если ВСЕ команды получили подтверждение "ok"; иначе — false (при первой ошибке).
Заметки
Команды отправляются строго последовательно с ожиданием подтверждения каждой. При ошибке отправки одной команды дальнейшие команды НЕ отправляются.
Предупреждения
Блокирует вызывающий поток на время выполнения всего списка команд.

◆ setLed()

bool FCMarlinController::setLed ( const QList< QColor > & colors,
uint8_t brightness = 255 )

Управляет светодиодной лентой через команды контроллера.

Аргументы
colorsСписок цветов для последовательного отображения на ленте (RGB).
brightnessЯркость ленты (0–255, где 255 = максимальная яркость).
Возвращает
true если команда управления лентой успешно отправлена и подтверждена; иначе — false.
Заметки
Формат команды зависит от конфигурации прошивки Marlin:
  • Для адресных лент (NeoPixel): M150 R<red> U<green> B<blue> P<brightness>,
  • Для ШИМ-управления: специфические M-коды в кастомной прошивке.
Предупреждения
Требует предварительной настройки пинов ленты в конфигурации прошивки Marlin.
