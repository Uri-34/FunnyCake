Подробное описание

Контроллер насосной рампы с интегрированными датчиками температуры.

Управляет группой насосов через I²C-интерфейс и мониторит температуру каждого насоса с помощью трёх датчиков LM75A. Обеспечивает:

  • Включение/выключение отдельных насосов по номеру,
  • Автоматическое отключение всех насосов при включении нового,
  • Мониторинг температуры через встроенные датчики,
  • Интеграцию в систему управления состоянием через FCConditionObject.

Архитектурные особенности:

  • Состояние насосной рампы управляется ТОЛЬКО через составное состояние (conditionChanged),
  • Специфичные сигналы (pumpSwitched, temperatureChanged) передают бизнес-данные,
  • НЕ проксирует сигналы состояния термометров — каждый компонент управляет своим состоянием,
  • Все операции ввода-вывода используют методы базового класса с автоматической установкой состояния.

Конфигурация оборудования:

  • Адрес контроллера насосов: 0x20 (7-битный),
  • Адреса термометров: 0x30 (t0), 0x31 (t1), 0x32 (t2),
  • Коды управления насосами: 0xFE (насос 0), 0xFD (насос 1), 0xFB (насос 2).
Предупреждения
Критически важно:
  • Перед включением насоса убедитесь, что все термометры в состоянии Ready,
  • При превышении критической температуры внешний код ДОЛЖЕН отключить насосы,
  • Все операции блокируют вызывающий поток на время транзакции I²C.
Заметки
Для встраиваемых систем: рекомендуется проверять температуру перед каждым включением насоса.

Конструктор контроллера насосной рампы.

Аргументы
busУказатель на шину I²C (должна быть инициализирована заранее).
parentРодительский QObject для управления временем жизни.
Заметки
При создании:
  • Инициализируются три датчика температуры на адресах 0x30, 0x31, 0x32,
  • Все насосы отключаются через вызов off(),
  • Устанавливается начальное состояние: {NotReady, Stop, NotChanged, NoError}.
