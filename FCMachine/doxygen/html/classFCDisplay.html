Подробное описание

Главное окно графического интерфейса системы управления плоттером (встраиваемая система).

Является центральным компонентом пользовательского интерфейса для встраиваемой платформы (Raspberry Pi + Buildroot). Обеспечивает:

  • Управление состоянием устройства через композицию с FCConditionObject,
  • Отображение списка моделей (SVG) с возможностью выбора и предпросмотра,
  • Контроль выполнения операций (старт/пауза/стоп),
  • Переключение между плоттерами через динамическое меню,
  • Экранную заставку при бездействии (таймаут 1 минута),
  • Консоль для отображения диагностических сообщений,
  • Модальные диалоги подтверждения и ошибок.

Архитектурные особенности:

  • Единая точка управления состоянием через механизм сигналов/слотов Qt,
  • Разделение ответственности: интерфейс (FCDisplay) ↔ логика (внешние контроллеры),
  • Поддержка сенсорного ввода через переопределение обработки событий,
  • Автоматическое управление ресурсами через родительские связи QObject.
Предупреждения
Класс НЕ является потокобезопасным — все операции с интерфейсом должны выполняться ТОЛЬКО в основном потоке (потоке событий Qt). Для взаимодействия с фоновыми потоками используйте сигналы/слоты с очередью соединений (Qt::QueuedConnection).
Заметки
Для встраиваемых систем с ограниченными ресурсами:
  • Избегайте частых перерисовок интерфейса (особенно при анимациях),
  • Ограничьте количество одновременно загруженных моделей в памяти,
  • Используйте кэширование изображений для ускорения отображения.
См. также
