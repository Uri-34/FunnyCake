Подробное описание

Абстрактный базовый класс для управления аппаратными устройствами в системе.

Ключевые принципы архитектуры:

  • ЕДИНСТВЕННЫЙ механизм уведомлений: сигнал conditionChanged() из базового класса,
  • Все изменения состояния передаются через составное состояние FCCondition,
  • Специализированные сигналы (started/stopped/readyChanged) УДАЛЕНЫ как избыточные,
  • Минимизация эмиссий сигналов через групповые установки состояния.
Предупреждения
Критически важно:
  • НИКОГДА не создавать специализированные сигналы для частей состояния, если базовый класс уже предоставляет сигнал для полного состояния,
  • Все проверки состояния выполняются через методы is() или анализ condition().
Заметки
Для встраиваемых систем: минимизация количества сигналов критична для производительности.
