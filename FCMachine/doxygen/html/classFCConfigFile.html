Подробное описание

Класс-одиночка (Singleton) для централизованного управления конфигурацией приложения.

Предоставляет доступ к путям файловых ресурсов, расширениям файлов и списку серийных номеров подключённых устройств (плоттеров). Использует QSettings в формате INI для персистентного хранения настроек.

Расположение конфигурационного файла:

  • На десктопных системах: рядом с исполняемым файлом (<имя_программы>.conf),
  • На встраиваемых системах (Raspberry Pi с Buildroot): в /etc/funnycake/ или /usr/local/etc/,
  • При отсутствии прав на запись: в директории пользователя (QStandardPaths).

Особенности реализации:

  • Строгая реализация паттерна Singleton (запрещено копирование и перемещение),
  • Ленивая инициализация при первом обращении к instance(),
  • Автоматическое создание значений по умолчанию при отсутствии конфигурационного файла,
  • Поддержка горячей перезагрузки конфигурации через методы load()/save().
Предупреждения
Класс НЕ является потокобезопасным — все операции должны выполняться в основном потоке приложения. Для многопоточного доступа используйте внешнюю синхронизацию (например, QMutex).
Заметки
Для встраиваемых систем с ограничениями файловой системы (только чтение, RAMFS):
  • При невозможности записи конфигурация сохраняется только в памяти,
  • Рекомендуется вызывать save() только при наличии подтверждённой возможности записи.
См. также
QSettings для деталей реализации персистентного хранения

Возвращает
true, если сохранение успешно; иначе — false (например, нет прав на запись).
